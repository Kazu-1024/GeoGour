# Geoグル（GeoGour）

現在地から近い飲食店を直感的に探せるグルメ検索Webアプリです。  
位置情報を起点に検索することで、「今いる場所からすぐ行けるお店」を  
迷わず見つけられる体験を目指しました。

---

## 概要

- ブラウザの位置情報を利用して周辺の飲食店を検索
- 検索条件入力から結果表示までをシンプルに設計
- ホットペッパー グルメサーチAPIを利用

---

## 主な機能

### ホーム画面
- 現在地取得（Geolocation API）
- 検索条件入力
  - 検索範囲
  - ジャンル（任意）
- 検索実行
- 最近見たお店の表示

### 検索結果画面
- 周辺飲食店の一覧表示
- ページング対応
- 店舗名・画像・ジャンル・アクセス表示

### 店舗詳細画面
- 店舗詳細情報表示
  - 店舗名
  - 住所
  - 営業時間
  - 定休日
  - 予算
  - 画像
- 地図表示（Google Maps 埋め込み）
- ホットペッパー予約ページへの遷移

### 閲覧履歴
- 店舗IDのみを保存
- 最大10件まで保持
- 30日経過した履歴は初回ロード時に自動整理
- 表示時にAPIから最新情報を取得

---

## 画面構成

- `/`  
  ホーム画面（検索条件入力・閲覧履歴表示）

- `/search`  
  検索結果画面（クエリパラメータ対応）

- `/shop/:id`  
  店舗詳細画面

## 設計・実装上の工夫

- 検索条件入力UIは `SearchFilter` として切り出し、  
  Home / Search 画面で再利用
- 検索条件はクエリパラメータで管理し、  
  リロードやURL共有にも対応
- ホットペッパーAPIの利用規約を考慮し、  
  店舗情報は保存せず、IDのみを保持
- Google MapsはAPIキー不要の埋め込み形式を採用し、  
  誰でも動作確認できる構成にしている
